# Mobile Cel

Prévia responsiva com a logo fornecida e identidade em branco e azul.

Abra `index.html` no navegador. Não requer instalação nem etapa de build. A pasta `dist/` contém a mesma página para hospedagem estática.

Os contatos apontam para o Beacons oficial. A composição de aparelhos é ilustrativa; modelos e disponibilidade devem ser confirmados com a loja.
